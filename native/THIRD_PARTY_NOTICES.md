## Rpack.js substitution table (RisuAI)

`app/src/main/java/space/sgu/next/data/RisuPreset.kt` embeds the 512-byte rpack map
(`src/ts/rpack/rpack_map.bin`) from RisuAI (https://github.com/kwaroran/Risuai) so that
SGU Next can read and write RisuAI `.risup` prompt preset files.
